The Architecture

How Ballast Works

01 // RETRIEVE

Connect & Ingest

Sync read-only windows from Gmail, GitHub PRs, and uploaded files. Ingested payloads are isolated into untrusted data blocks, never blended into prompt instructions.

02 // THE CRITIC GATE

Dual-Gate Audit

A separate, isolated Critic function validates every proposed sentence against retrieved quote spans. Unsourced assertions are dropped entirely—never footnoted or guessed.

03 // SHIP & PROPOSE

Citable Brief & Actions

Export dated markdown and PDF briefs with version lineage. Follow-up action drafts are proposed with human gating—nothing executes without explicit owner approval.
